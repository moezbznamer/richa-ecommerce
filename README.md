# RICHA | Modern Animated Clothing

Discover RICHA, your destination for modern clothing, anime-inspired designs, and personalized fashion.

## 🌟 Overview

**RICHA** is a high-performance, modern animated clothing e-commerce web application featuring luxury streetwear, anime-inspired capsule collections (such as the Otaku / Itachi Zone), custom design requests, and a loyalty rewards tier system.

## ✨ Key Features

- **Luxury Streetwear & Anime Collections**: Catalog featuring Men, Women, Kids, Otaku, and Special Offer collections.
- **Custom Design Studio**: Dedicated interface for custom clothing requests with file uploads.
- **Multilingual Support**: Fully localized in French (`fr`), English (`en`), and Arabic (`ar`) with RTL support.
- **Cart & Order System**: Complete cart management with stock deduction and order lifecycle tracking.
- **Loyalty Tier Progression**: Dynamic user level bar and milestone rewards based on spending.
- **Role-Based Admin Suite**: Protected dashboard for inventory stock management, product addition with multi-color image variants, and order oversight.
- **Mobile-First Experience**: Tailored mobile navigation bar, swipeable image galleries, and quick filters.

## 🛠️ Tech Stack

- **Framework**: React 18 with TypeScript
- **Bundler & Dev Server**: Vite
- **Styling**: Tailwind CSS & shadcn/ui (Radix UI primitives)
- **Animations**: Framer Motion & canvas-confetti
- **Internationalization**: i18next & react-i18next
- **Backend & Database**: Supabase (PostgreSQL, Storage, Row-Level Security, Edge Functions)
- **Icons**: Lucide React

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or bun

### Installation

1. Clone or navigate to the project repository:
   ```bash
   cd richa-animated-boutique
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure environment variables in `.env`:
   ```env
   VITE_SUPABASE_URL="https://your-project.supabase.co"
   VITE_SUPABASE_PUBLISHABLE_KEY="your-supabase-anon-key"
   VITE_SUPABASE_PROJECT_ID="your-project-id"
   ```

4. Start development server:
   ```bash
   npm run dev
   ```

5. Build for production:
   ```bash
   npm run build
   ```

6. Preview the production build:
   ```bash
   npm run preview
   ```
